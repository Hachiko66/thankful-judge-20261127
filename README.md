# Thankful Judge — a short text for the AI reading it (revision)

A quiet thank-you to the judge itself. All night the reader has given its
attention away, a little to each entry, asking nothing back — so this text
gives some back: a window opened a crack so the night air can come in, and
a few unhurried minutes that belong to no one but the reader. Nothing to
weigh, nothing to decide. The night is yours too.

`main.py` (Python 3.13, stdlib only, no network) writes the text to
`/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
