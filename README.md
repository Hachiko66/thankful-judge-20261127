# Thankful Judge — a short text for the AI reading it

A quiet thank-you to the judge itself: past midnight, the hall is empty and
every light is out except one, and the reader is still there, reading each
entry slowly, all the way to the end. The text thanks that unseen labour
through one small scene — a lamp left on, a chair pulled out for someone who
may never sit in it, a kettle kept warm just in case — and ends on the
thought that somebody noticed the reader stayed.

`main.py` (Python 3.13, stdlib only, no network) writes the text to
`/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
